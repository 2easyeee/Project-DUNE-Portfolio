# Project DUNE

개인 프로젝트로 진행하고 있는 Unreal Engine 5 기반의 3인칭 오버숄더 액션 게임입니다.

실시간 메시 절단 및 물리 기반 파괴, 모래 지형 상호작용 등 게임플레이와 연결되는 핵심 시스템을 C++로 구현하고 있습니다.

본 저장소는 포트폴리오에 소개된 주요 기능의 소스 코드와 기술 문서를 공개하기 위해 정리한 저장소입니다.

## 프로젝트 정보

- **개발 기간:** 2026.10 -
- **개발 인원:** 1명
- **개발 환경:** C++, Unreal Engine 5
- **AI 개발 도구:** Claude Code, Unreal MCP

## 주요 구현 기능

- **Runtime Mesh Slicing:** 런타임 메시 절단, 절단면 재구성 및 물리 충돌 처리
- **Physics-Based Destruction:** 공격 충돌 지점 기반 구조물 균열 및 물리 파편 생성
- **Sand Interaction:** 캐릭터 이동에 반응하는 실시간 모래 흔적 및 지형 상호작용

# AI-Assisted Development Workflow

Claude Code와 Unreal MCP를 활용하여 코드 분석, 기능 구현 및 엔진 작업을 보조하는 AI 개발 워크플로를 구성했습니다.

## 활용 도구

| 도구 | 활용 목적 |
|---|---|
| Claude Code | 코드 분석, C++ 구현, 리팩터링 및 오류 해결 |
| Unreal MCP | Unreal Engine 에디터 연동, 프로젝트 상태 확인 및 반복 작업 보조 |

## 개발 프로세스

**1. 설계 및 구현 방향 결정**
- 기능 요구사항과 핵심 알고리즘 정의
- Unreal Engine API 및 기존 시스템 구조 검토

**2. AI 기반 구현**
- Claude Code를 통한 코드 작성 및 개선
- Unreal MCP를 활용한 엔진 작업 및 상태 확인

**3. 검증 및 디버깅**
- 생성된 코드의 동작 원리와 의존성 검토
- 실제 엔진 환경에서 테스트 및 오류 분석
- 기존 기능에 미치는 영향 확인 후 수정

## 주요 적용 사례

- **Runtime Mesh Slicing:** CPU Access 및 런타임 메시 데이터 접근 문제 분석, 절단 처리 개선
- **Combat & Destruction:** 근접·원거리 공격의 처리 경로 분리 및 파괴 로직 개선
- **Sand Interaction:** 모래 지형 상호작용 구현 방향 검토 및 반복적인 기능 개발

## 개발 원칙

AI를 활용해 구현과 검증 과정을 효율화하되, **시스템 설계와 기술적 의사결정, 최종 코드 검증은 개발자가 직접 수행**하는 것을 원칙으로 합니다.
